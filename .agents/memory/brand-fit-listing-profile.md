---
name: Brand-fit listing profile
description: Durable rule for owner context and verification signals shown to sponsoring brands.
---

Brand-fit context should travel with each listing: where the item is seen, why it is used, the owner's claimed social reach, and public profile links for verification.

**Why:** Brands choose a person and placement, not only an item, so this context must remain available after the owner posts and older listings must still render safely.

**How to apply:** Persist profile fields on new listings and use clear fallback copy when a legacy listing has no purpose statement or linked social profiles.
