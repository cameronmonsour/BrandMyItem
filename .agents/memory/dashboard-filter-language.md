---
name: Dashboard filter language
description: Durable visual convention for BrandMyItem dashboard filters.
---

Dashboard filters should use compact inset-grouped rows with quiet section labels, restrained separators, right-aligned values, and native-feeling selection states. Avoid stacking a separate rounded card around every small group of fields.

**Why:** The repeated form-card treatment made the dashboard feel generic and visually heavy rather than aligned with the product's Apple-inspired direction.

**How to apply:** Keep filters grouped by meaning, preserve generous touch targets, show values and disclosure marks clearly, and use borders or elevation only for the grouped surface rather than each individual control.
