## 0. Global rules (apply everywhere)

**Vocabulary — locked.** Use exactly these words, site-wide, in UI and copy:
- **funded** — never "sold", "claimed", "purchased" for spots or listings
- **listing** — never "campaign" for an owner's item (the brand-facing dollar figure is still called "campaign total")
- **term** — never "commitment"
- **owner** — never "user"
- **spot** — never "placement" or "ad space" in UI labels (prose in the bento can keep "ad space" where it's already locked)

**Catalog phone — locked.** The phone is the **iPhone 17**, not the 17 Pro. Two tiers: 256GB and 512GB. Unlocked prices $829 / $1,029. Campaign total = retail × 1.4 → $1,161 / $1,441. Specs: A19 chip, 6.3" Super Retina XDR, 48MP Fusion main + 48MP Fusion Ultra Wide, 256GB–512GB. Source line: "Official Apple product page". Replace every "iPhone 17 Pro" string and every Pro-derived number ($1,099, $1,539, $2,099, $1,499, 1TB) across hero, picker, live card, bento, ticker, spec panel, and any JSON/config.

**Catalog data — single source of truth.** Move all item names, brand names, storage/size/finish options, base prices, price deltas, and spec rows into one config object/file. Hero, picker, live card, bento demo, ticker, and spec panel all read from it. No hardcoded prices in templates.

**Brand-facing money.** Brands see ONE number per listing: **Campaign total $X · N spots**, with the single line: *"Includes the item, tax, branding application, delivery, and check-in verification."* No itemized breakdown anywhere. "Retail $X" appears only in the owner configurator spec panel.

**Apple marks.** No Apple logo in any render. Product names (MacBook Pro, iPhone 17, AirPods Max, RIMOWA, YETI, Stanley) appear only as item identifiers in the catalog/picker/card — never in headlines or marketing copy. Never use the word "Memoji" anywhere in the UI.

**Dev artifacts.** Remove the floating page-minimap thumbnail (bottom-right) and the small blue dot in the nav bar (top-right). Remove any other dev/debug overlays.
